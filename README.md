# CardBackendService

## Load .env in PowerShell and run

1. Copy the example file and fill in your real password:
   - `Copy-Item .env.example .env`
2. Load all values from `.env` into your current shell session:
   - `Get-Content .env | ForEach-Object { if ($_ -and -not $_.StartsWith('#')) { $name, $value = $_ -split '=', 2; [System.Environment]::SetEnvironmentVariable($name, $value, 'Process') } }`
3. Start the Spring Boot app:
   - `.\mvnw.cmd spring-boot:run`

Notes:
- `.env` should stay local and never be committed.
- The app reads `RDSHOST`, `RDSUSER`, `RDSPASSWORD`, `PGSSLMODE`, and `PGSSLROOTCERT` from environment variables.

## Cards Database Structure

The backend uses PostgreSQL table `public.card`.

```sql
CREATE TABLE IF NOT EXISTS public.card (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    card_name VARCHAR(255) NOT NULL,
    card_type VARCHAR(255) NOT NULL,
    card_bank VARCHAR(255) NOT NULL,
    has_annual_fee BOOLEAN NOT NULL,
    annual_fee INTEGER,
    rating DOUBLE PRECISION NOT NULL,
    bonus BIGINT,
    bonus_spend BIGINT,
    cashback_flat DOUBLE PRECISION,
    cashback_travel DOUBLE PRECISION,
    cashback_dining DOUBLE PRECISION,
    cashback_grocery DOUBLE PRECISION,
    cashback_gas DOUBLE PRECISION,
    cashback_pharmacy DOUBLE PRECISION,
    cashback_lyft DOUBLE PRECISION,
    cashback_officesupply DOUBLE PRECISION,
    cashback_services DOUBLE PRECISION,
    cashback_brand DOUBLE PRECISION,
    cashback_other DOUBLE PRECISION,
    credit_score INTEGER,
    image_s3_key TEXT,
    image_source_url TEXT
);
```

### Quick DB verification

- Show columns:
  - `psql "host=$env:RDSHOST port=5432 dbname=postgres user=$env:RDSUSER sslmode=verify-full sslrootcert=$env:PGSSLROOTCERT password=$env:RDSPASSWORD" -c "\d+ public.card"`
- Check image fields:
  - `psql "host=$env:RDSHOST port=5432 dbname=postgres user=$env:RDSUSER sslmode=verify-full sslrootcert=$env:PGSSLROOTCERT password=$env:RDSPASSWORD" -c "SELECT id, card_name, image_s3_key, image_source_url FROM public.card ORDER BY id LIMIT 20;"`

## API Endpoints

Base path: `http://localhost:8080/card`

### GET endpoints

- `GET /card/all`
  - Returns all cards.
- `GET /card/{id}`
  - Returns card by numeric id.
- `GET /card/name/{name}`
  - Returns a card by exact name.
  - URL-encode spaces, example: `Chase%20Freedom%20Unlimited`
- `GET /card/top4-rating-cards`
  - Returns top 4 rated cards.
- `GET /card/type/{type}`
  - Returns cards by type (example: `travel`, `cashback`, `secured`).
- `GET /card/bank/{bank}`
  - Returns cards by bank (example: `Chase`, `Citi`).
- `GET /card/has-annual-fee/{hasAnnualFee}`
  - Returns cards by annual fee flag (`true` or `false`).

### POST endpoint

- `POST /card/add`
  - Creates a new card.
  - Request body: full `Card` JSON.

Example:
```bash
curl -X POST "http://localhost:8080/card/add" \
  -H "Content-Type: application/json" \
  -d '{
```

## GraphQL API

GraphQL endpoint:
- `POST http://localhost:8080/graphql`

### GraphQL Queries

- Paginated cards with optional filters:

```graphql
query CardsPage {
  cards(page: 0, size: 20, bank: "Chase", type: "travel", hasAnnualFee: true) {
    page
    size
    totalElements
    totalPages
    hasNext
    content {
      id
      cardName
      cardBank
      cardType
      imageS3Key
      imageSourceUrl
    }
  }
}
```

- Card by id:

```graphql
query CardById {
  cardById(id: 1) {
    id
    cardName
    cardBank
    imageS3Key
    imageSourceUrl
  }
}
```

- Card by name:

```graphql
query CardByName {
  cardByName(name: "Chase Freedom Unlimited") {
    id
    cardName
    cardType
    cardBank
  }
}
```

- Top rated cards:

```graphql
query TopRated {
  topRatedCards(limit: 4) {
    id
    cardName
    rating
  }
}
```
